# family-finance-app

Compiled output of [Finance HQ](https://github.com/DD-Builder/Family-Finance), a
local-first family-office command center.

**This repo holds the compiled bundle only — no source code lives here.**
Source is in a separate private repo. Each deploy replaces the entire
contents of `main` (orphan history) so this repo never accumulates build
history or source artifacts.
